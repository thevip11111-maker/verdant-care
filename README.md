# Verdant Care

Design Aesthetics: Use a refined, minimalist aesthetic (clean typography, generous whitespace, a soothing sage-and-neutral color palette) to avoid a "vibe-coded" look.

Core Features: Include user authentication, a home dashboard showing user plants, an interactive AI camera scanner interface with real-time analysis, and a detailed plant care and watering schedule view.

Prompt:

Build a production-grade, modern, and premium mobile-first web app for plant disease detection and care management. The design must feel professional, clean, and polished (avoiding generic or toy-like aesthetics), utilizing a sophisticated nature-inspired palette (deep slate, soft sage green, crisp white, and subtle dark mode support).




Key Screens & Requirements:




Authentication: Clean login and signup screens with email/password and social auth options, featuring smooth transitions.

Home Dashboard:




A personalized greeting with an overview of user-added plants.

Status indicators for watering reminders and health alerts.

Quick-action buttons to scan a new plant or view reminders.

AI Scanner View:




An interactive camera/upload interface where users can take a photo or upload an image of a diseased plant leaf.

An analysis state with a loading animation simulating AI inspection.

Results screen displaying the predicted disease name, a prominent certainty percentage bar, and actionable treatment recommendations.

Plant Care & Reminders:




Detailed profiles for individual plants with specific care advice (sunlight, soil, humidity).

A dedicated watering schedule tracker with push/in-app reminder notifications.

Use modern Tailwind CSS styling, Lucide icons, and responsive layouts. Ensure the codebase is clean, modular, and ready for backend integration.

Design & Typography Guidelines:




Color Palette: Pure white (#FFFFFF) background, deep forest green (#0F3822 / #164E2A) for primary actions/accents, emerald (#10B981) for health badges/success states, and cool light gray (#F8FAFC / #F1F5F9) for secondary card containers. Avoid dark navy gradients, vibrant purples, or colorful glow effects.

Typography: Replace all decorative serif fonts with a crisp, clean neo-grotesque sans-serif font system (such as Inter, Plus Jakarta Sans, or SF Pro). Use tight line heights, bold structural headings, and crisp micro-copy.

UI Polish:




Replace glassmorphic blurs with subtle 1px borders (border-slate-200) and soft, minimal drop shadows.

Ensure high contrast with crisp dark text (#0F172A) over bright white cards.
